# 🛒 বাজার দর (BazarDor) - প্রয়োজনীয় পণ্যের দাম এক নজরে

## 📌 প্রজেক্ট পরিচিতি (Project Overview)

**বাজার দর (BazarDor)** হলো একটি আধুনিক, দ্রুতগতির এবং সম্পূর্ণ রেসপনসিভ ওয়েব অ্যাপ্লিকেশন যার মাধ্যমে বাংলাদেশের নিত্যপ্রয়োজনীয় দ্রব্যাদি (চাল, ডাল, তেল, সবজি, মাছ, মাংস, ডিম-দুধ এবং মসলা)-র প্রতিদিনের বাজারদর, পাইকারি ও খুচরা মূল্য, বিভাগভিত্তিক ও বাজারভিত্তিক তারতম্য এবং মূল্যবৃদ্ধির শতকরা হার এক নজরে পর্যবেক্ষণ করা যায়।

অ্যাপ্লিকেশনটি ফিগমা (Figma) ডিজাইনের অনুকরণে অত্যন্ত নিখুঁতভাবে তৈরি করা হয়েছে এবং এতে বাংলা সংখ্যামালা (Bengali Numerals) ও আধুনিক ইউজার ইন্টারফেস সাপোর্ট নিশ্চিত করা হয়েছে।

---

## 🚀 প্রধান ৫টি বৈশিষ্ট্য (5 Key Features)

1. **রিয়েল-টাইম প্রাইস ট্র্যাকিং ও মারকুই টিকার (Price Ticker Strip):**
   - নেভবারের নিচে একটি নিরবচ্ছিন্ন অ্যানিমেটেড ইনফিনিট মারকুই স্ক্রলিং স্ট্রিপ, যাতে পণ্য আইকন, নাম, একক এবং শতকরা হ্রাস/বৃদ্ধির হার (▲/▼) প্রদর্শিত হয়। হোভারে স্ক্রল থামে এবং যেকোনো পণ্যে ক্লিক করে সরাসরি বিস্তারিত তথ্য দেখা যায়।

2. **দৈনিক হ্রাস-বৃদ্ধি ও সামগ্রিক বাজার তালিকা (Daily Risers & Fallers):**
   - হোম পেজে শীর্ষ ৬টি মূল্যবৃদ্ধি পাওয়া পণ্য (**"▲ আজ দাম বেড়েছে"**), শীর্ষ ৬টি মূল্যহ্রাস পাওয়া পণ্য (**"▼ আজ দাম কমেছে"**) এবং সকল পণ্যের রেসপনসিভ গ্রিড কার্ড। প্রতিটি কার্ডে বাংলা সংখ্যায় দাম ও ব্যাজ সংযুক্ত।

3. **বাজারভিত্তিক বিস্তারিত দাম ও পরিসংখ্যান (Market-wise Price Summary - Protected Route):**
   - `/product/[slug]` রুটে পণ্যের সর্বনিম্ন, সর্বাধিক এবং গড় মূল্য তালিকা। ঢাকা, চট্টগ্রাম, রাজশাহী, খুলনা, সিলেট, ময়মনসিংহসহ বিভিন্ন বিভাগের একাধিক বাজারের সর্বনিম্ন, সর্বোচ্চ এবং গড় দর সারণী আকারে প্রদর্শিত। রুটটি সুরক্ষিত (Protected Route), তাই লগইন ছাড়া প্রবেশ করতে চাইলে স্বয়ংক্রিয়ভাবে নোটিফিকেশনসহ সাইন-ইন পেজে রিডাইরেক্ট করে।

4. **সাজানোর আধুনিক ব্যবস্থা (Numeric Sort Control - Challenge C1):**
   - ক্যাটাগরি পেজে পণ্যের দাম অনুযায়ী **"ডিফল্ট"**, **"দাম: কম থেকে বেশি"** এবং **"দাম: বেশি থেকে কম"** অনুযায়ী নির্ভুল সর্টিং। বাংলা সংখ্যামালা হলেও অভ্যন্তরীণভাবে প্রকৃত সাংখ্যিক মান (Numeric Value) অনুযায়ী ক্রমানুসারে সাজানো হয়।

5. **BetterAuth ইন্টিগ্রেশন ও প্রোফাইল আপডেট (BetterAuth & Profile Update - Challenge C3):**
   - ইমেইল/পাসওয়ার্ড ও সোশ্যাল লগইন (Google ও GitHub) সুবিধা।
   - প্রোফাইল পৃষ্ঠায় ব্যবহারকারীর তথ্যাদি দেখা এবং `/profile/update` রুটের মাধ্যমে নাম আপডেট করার সুবিধা (BetterAuth `updateUser` গাইডলাইন অনুসরণ করে তৈরি)।
   - react-hot-toast দিয়ে প্রতিটি ক্রিয়াকলাপে দৃষ্টিনন্দন টোস্ট নোটিফিকেশন।

## 🧭 এপিআই এন্ডপয়েন্টসমূহ (API Endpoints)

অ্যাপ্লিকেশনটিতে ক্লাউডফ্লেয়ার ওয়ার্কার্সে হোস্ট করা দুটি ব্যাকআপ এপিআই ও লোকাল ক্যাশ যুক্ত রয়েছে:
- **Base URL 1:** `https://api.api-store.workers.dev/api/bazardor`
- **Base URL 2:** `https://api.abcz.workers.dev/api/bazardor` (Fallback)
- **সকল পণ্য:** `/products`
- **ক্যাটাগরি অনুযায়ী ফিল্টার:** `/products?category=chal`
- **একক পণ্য:** `/products/:id` বা `/products/:slug`
- **ক্যাটাগরিসমূহ:** `/categories`
- **একক ক্যাটাগরি:** `/categories/:slug`

## 💻 লোকাল কম্পিউটারে রান করার নিয়ম (Getting Started)

### ১. রিপোজিটরি ক্লোন করুন
```bash
git clone https://github.com/your-username/bazardor.git
cd bazardor
```

### ২. প্যাকেজসমূহ ইনস্টল করুন
```bash
npm install
```

### ৩. এনভায়রনমেন্ট ভ্যারিয়েবল সেটআপ করুন
প্রজেক্টের রুটে `.env.local` ফাইল তৈরি করুন:

BETTER_AUTH_URL="http://localhost:3000"
NEXT_PUBLIC_APP_URL="http://localhost:3000"

### ৪. ডেভেলপমেন্ট সার্ভার চালু করুন
```bash
npm run dev
```
ব্রাউজারে [http://localhost:3000](http://localhost:3000) ওপেন করে প্রজেক্টটি উপভোগ করুন!
